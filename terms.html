利用条件

対象：Sena LIVE Tools ／ 最終更新日：2026年10月31日

この文書は、配信者本人が個人用アプリSena LIVE Toolsを使用する際の条件を説明します。本アプリは一般向けのオンラインサービスではなく、利用登録や第三者へのサービス提供を受け付けません。

1. 利用する機能と本人の許可

本アプリは、本人が指定したTikTok LIVEの監視、Discord通知、コメント保存、ローカル録画への合成、本人のYouTubeチャンネルへの送信を行います。本人が各接続先を設定して自動処理を有効にした範囲で動作します。Googleへのアクセスは、Googleの認可画面で本人が許可した権限の範囲に限ります。

利用にあたってはプライバシーポリシーを確認し、情報の取得・保存・外部送信に同意してください。必要な権利や許可のある配信・録画を対象に使用し、コメント投稿者など第三者の権利やプライバシーにも配慮してください。

2. YouTubeへの自動アップロード

本アプリはYouTube API Servicesを使用します。本アプリを利用することにより、YouTubeの利用規約にも従うことに同意します。Googleによる情報の取り扱いはGoogleのプライバシーポリシーをご確認ください。

本人が許可した自動処理として、対象録画のコメント合成後に、指定チャンネルへ動画を送信します。毎回の投稿操作を本人が行う方式ではありません。設定は「限定公開」「子ども向けではありません」、登録者へのアップロード通知なしです。これらの設定が実際の内容に適切かは本人が確認してください。

限定公開はリンクを知っている人が閲覧・共有できる設定です。送信済み動画の削除や公開範囲の変更はYouTube Studioで行えます。Googleへのアクセス権は、Googleアカウントの設定から取り消せます。

3. 自動処理の停止とデータ管理

本人はローカルアプリの停止操作によって監視と自動処理を停止できます。処理中の変換や送信は、安全な区切りまで進む場合があります。停止によって、すでに送信された通知や動画、保存済みのコメントが自動的に取り消されることはありません。

元の録画、生成した動画、コメント、処理記録、バックアップを保管・削除するのは本人です。不要なデータの削除方法はプライバシーポリシーに記載しています。

4. 動作上の制約

ネットワーク停止、PCのスリープ、外部サービスの仕様変更や利用制限により、検知の遅れ、コメントの欠落、時刻のずれ、変換や送信の保留が発生する場合があります。すべてのコメントの取得や、常時の無人運転が必ず成功することを保証するものではありません。

配信と録画の対応付けが不明な場合や、送信結果を確定できない場合は、誤った動画や二重投稿を避けるため確認待ちにすることがあります。本人が状態を確認し、必要な設定や再連携を行います。

5. 外部サービスとの関係

Google、YouTube、TikTok、Discord、接続準備サービスの利用には、各サービスの規約やポリシーが適用されます。本アプリは、それらの会社による公式製品、公認サービス、または動作保証付きの連携機能を意味しません。
