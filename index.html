PERSONAL LIVE ARCHIVE TOOL

配信の記録を、
コメントと一緒に。

Sena LIVE Tools は、配信者本人のWindows PCで動く個人用アプリです。TikTok LIVEの開始通知、コメントの保存、録画へのコメント表示、本人のYouTubeチャンネルへのアップロードを補助します。

一般ユーザー向けのサービス、登録受付、アプリ配布サイトではありません。

データの取り扱いを確認利用条件を確認

配信からアーカイブまで

01 / DETECT

LIVEの開始を確認

15秒間隔で配信状態を確認し、設定されたDiscordサーバーに開始通知を送ります。

02 / RECORD

コメントを記録

ユーザー名、本文、時刻、LIVE開始からの経過時間を、配信ごとに保存します。

03 / OVERLAY

録画に重ねる

保存済みの録画に、淡い青の角丸枠でコメントを表示。最新の発言を下に置き、上へ流します。

04 / UPLOAD

YouTubeへ送信

本人が許可した自動処理として、コメント付き動画を指定チャンネルへ限定公開でアップロードします。

Googleとの連携について

本アプリはYouTube API Servicesを利用します。本人がGoogleの認可画面で連携を許可すると、YouTubeチャンネルと既存動画の情報を読み取り、投稿先の確認やタイトルの重複防止に使います。動画のアップロード権限は、本人のアーカイブ動画を送信するために使います。

Googleのパスワードをアプリに入力・保存する必要はありません。認可したチャンネルと設定された投稿先が一致することを確認してから処理します。Googleの連携はGoogleアカウントのアクセス権設定から取り消せます。

アップロードは、本人が有効にした自動処理です。
配信終了後に、対象録画を合成して送信します。毎回投稿ボタンを押す方式ではありません。公開範囲は「限定公開」、動画の設定は「子ども向けではありません」です。限定公開動画は、リンクを知っている人が閲覧・共有できるため、非公開動画とは異なります。

保存と外部サービス

コメントや処理記録、録画は本人のPCに保存します。通知にはDiscord、LIVEの取得にはTikTokと接続準備サービス、認証と動画送信にはGoogle／YouTubeへの通信が発生します。保存する情報や送信先は、プライバシーポリシーで説明しています。

通信障害や外部サービスの変更により、検知の遅れ・コメントの欠落・処理の保留が起こることがあります。未取得のコメントを完全に復元する機能はありません。

管理者・お問い合わせ

本アプリは、下記チャンネルの配信者が自身の配信アーカイブを管理するために使用します。内容の確認やデータの取り扱いに関する相談は、公開チャンネルから管理者にご連絡ください。

管理者の公開チャンネル

公開コメント欄にパスワード、認証コード、トークン、非公開の動画リンクなどを書き込まないでください。
