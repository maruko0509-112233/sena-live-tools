DATA & PRIVACY

プライバシーポリシー

対象：Sena LIVE Tools ／ 最終更新日：2026年10月31日

Sena LIVE Tools は、配信者本人が自分のWindows PCで利用するアーカイブ管理アプリです。一般ユーザーの登録を受け付けるサービスではありません。この文書は、本アプリがアクセスし、使用し、保存し、外部へ送信する情報を説明します。

1. 取り扱う情報と利用目的

情報内容・目的
Google／YouTube認可されたチャンネルのID・表示名、既存動画のタイトル等のメタデータ、送信した動画のID・公開状態・子ども向け設定・処理状態を読み取ります。投稿先の照合、同名タイトルの連番付与、アップロード結果の確認に利用します。
Google認証情報OAuthクライアント情報、アクセストークン、更新トークン、許可された権限と有効期限を扱います。許可された操作とバックグラウンド送信の継続に利用します。Googleのパスワードは取得しません。
TikTok LIVE対象配信のID、タイトル、開始・終了に関する情報、コメント投稿者の表示名・ユーザーID、本文、投稿・受信時刻、経過時間を記録します。通信解析や復旧のため、コメント以外の公開LIVEイベントを含み得る受信データの原本も保存します。
録画と処理記録本人が保存した録画、その音声、コメントを合成した動画、ファイル情報、処理結果、通信断や再試行の記録を扱います。動画の生成、対応付け、障害調査、二重投稿の防止に利用します。
Discord接続情報本人が指定したWebhookと通知の送信結果を扱います。指定されたサーバーへLIVE開始を通知するために利用します。

Googleへの権限要求は youtube.readonly と youtube.upload です。Gmailの閲覧やGoogle Driveの読み取りを、このアプリの機能として要求しません。

2. 外部へ送信する情報

  • Google／YouTube：認証・権限更新のためのOAuth通信と、本人が許可したコメント付き動画・タイトル・説明・公開設定の送信を行います。動画にはTikTokのコメントと表示名が含まれます。連携したGoogleの情報をDiscordやTikTokの署名サービスへ転送する機能はありません。
  • Discord：指定されたWebhook宛てに、LIVE開始文、LIVEリンク、@everyone のメンションを送信します。この通知で録画ファイルやGoogle認証情報は送信しません。
  • TikTok：LIVE状態の確認とコメント受信のため、対象アカウント・配信IDなどのリクエスト情報を送ります。現在の構成は、TikTokのパスワードやログインCookieを使わない匿名接続です。
  • Euler Streamの接続準備サービス：TikTokへの接続に必要な情報を得るため、配信ID、接続方式、クライアント名、User-Agentなどが送られます。接続先には通信元IPアドレスも伝わり、接続準備の過程で対象LIVEの公開データが扱われる場合があります。

外部サービス側に送信した情報は、各サービスの規約・ポリシーに従って取り扱われます。本アプリはYouTube API Servicesを利用し、Googleによる取り扱いにはGoogleのプライバシーポリシーが適用されます。

3. Googleユーザーデータの限定的利用

Google APIから受け取った情報の利用および他のアプリへの転送は、Google API Services User Data Policyの限定的利用（Limited Use）要件に従います。利用目的は、この文書で説明する本人向けのチャンネル確認、アーカイブ投稿、処理確認に限ります。

Googleユーザーデータを販売せず、広告配信や広告用プロフィールの作成、汎用AIモデルの学習には利用しません。本アプリの通常動作に、GoogleユーザーデータをAIサービスへ送る機能はありません。管理者が障害調査を行う場合も、その目的に必要な情報だけを扱います。

4. ローカル保存と保護

録画、コメント、処理記録は本人のPC内のファイルやデータベースに保存します。Googleのトークン、OAuthクライアント情報、DiscordのWebhook、アップロード再開URLはWindows DPAPIで暗号化して保管します。一般の録画やコメントファイルを、アプリ独自の方式で暗号化する機能はありません。

アプリからの通常のAPI通信にはHTTPSを使用します。PCのアクセス制御、バックアップ、ディスク暗号化は本人が管理します。読み込む前のダウンロード済みOAuthクライアントJSONは、アプリが自動で削除するものではありません。

5. 保存期間と削除

ローカルの録画・コメント・処理記録には、現在の実装で一律の自動削除期限を設定していません。本人がアプリを停止したうえで、不要になった録画、コメント、エクスポート、処理記録を削除できます。利用を終了するときは、Googleの連携を解除し、不要な認証情報と保存データも削除してください。バックアップがある場合は、そのコピーも本人の管理対象です。

YouTubeに送信した動画は、YouTube Studioから削除・公開設定の変更ができます。ローカルの動画を削除しても、YouTubeの動画は削除されません。YouTube側で削除しても、ローカルの元動画や記録は残ります。Discordに送信済みの通知も、アプリを停止しただけでは消えません。

コメントの表示や保存について相談がある場合は、下記の管理者窓口から対象の配信や内容をお知らせください。公開された欄へ秘密情報を記載しないでください。

6. Googleのアクセス権の取り消し

Googleアカウントのアクセス権設定から、本アプリのGoogleデータへのアクセスを取り消せます。取り消し後、新たなYouTube API操作には再連携が必要になります。実行中の処理も止めたい場合は、先にローカルアプリを停止してください。

アクセス権の取り消しだけでは、PCに保存した記録や送信済みの動画は削除されません。保存データの削除は前項の方法で行います。

7. この案内ページについて

この案内ページには、広告、アクセス解析タグ、埋め込み動画、ログインフォーム、独自Cookieを設けていません。外部リンクを開いた場合は、そのリンク先のサービスに接続します。ページの配信元が、配信や保守のためにIPアドレス、アクセス時刻、User-Agentなどをアクセスログとして扱う場合があります。配信元による取り扱いには、そのサービスのプライバシーポリシーが適用されます。
